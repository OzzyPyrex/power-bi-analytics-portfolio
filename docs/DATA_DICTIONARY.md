# Synthetic Data Dictionary

`examples/synthetic_workflow_data.csv` is fictional portfolio data created solely for demonstration.

| Field | Meaning | Safe use |
| --- | --- | --- |
| `Month` | First day of a reporting month | Trend and time-intelligence visuals |
| `Region` | Fictional service area | Comparison slicer or grouping |
| `ServiceLine` | Fictional workflow category | Comparison slicer or grouping |
| `NewCases` | Synthetic number of work items received | Demand KPI |
| `CompletedCases` | Synthetic number of work items completed | Throughput KPI |
| `OpenBacklog` | Synthetic outstanding work at month end | Backlog KPI |
| `OnTimeRate` | Fabricated share completed within a fictional target | Service-level KPI |
| `MedianReviewDays` | Fabricated median elapsed review time | Timeliness KPI |

No column represents a real person, organisation, client, case, financial amount, or operational result.
