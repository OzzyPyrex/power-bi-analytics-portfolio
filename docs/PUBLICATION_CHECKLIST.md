# Public Power BI Publication Checklist

Use this checklist before committing any Power BI portfolio material.

## Source and model

- [ ] The PBIX/PBIT was rebuilt from synthetic or approved public data.
- [ ] The model contains no original records, identifiers, file paths, connection strings, parameters, or credentials.
- [ ] Queries and data sources have been reviewed for hidden metadata.
- [ ] Measures, targets, and narrative text use fictional values unless public disclosure is approved.

## Visuals and assets

- [ ] Screenshots have no people, contact details, customer names, case references, client logos, or internal URLs.
- [ ] Images, theme files, and custom visuals have been checked for embedded brand assets.
- [ ] Visual labels clearly state when data is synthetic.

## Repository release

- [ ] Raw PBIX/PBIT, exports, workbooks, PDFs, and source screenshots remain uncommitted.
- [ ] The repository contains a clear data dictionary and build notes.
- [ ] A clean clone was inspected to confirm ignored source files are absent.
- [ ] Publication approval has been obtained where any non-synthetic material remains.
